# 战棋对战

## 文件说明

- `index.html`：页面入口
- `style.css`：界面样式
- `heroes.js`：英雄数据与规则说明
- `game.js`：游戏引擎、回合与技能结算
- `avatars/`：英雄头像图片
- `icons/`：技能图标预留目录

## 上传到 GitHub Pages

把上述文件直接放在仓库根目录，然后在 `Settings -> Pages` 中选择 `main / root`。

## 头像文件

当前默认头像文件名：

- `avatars/sword.png`
- `avatars/sukuna.png`
- `avatars/gojo.png`
- `avatars/archer.png`
- `avatars/mountain.png`
- `avatars/night.png`

## 技能图标

`icons/` 目录是预留位置。后续只要把技能图标图片放进去，并在代码里引用对应路径即可。
