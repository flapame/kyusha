# 9×4 战棋对战

这是一个适合直接上传到 GitHub Pages 的网页版战棋项目。

## 文件结构

- `index.html`：页面结构
- `style.css`：样式
- `heroes.js`：英雄数据和规则说明
- `game.js`：游戏引擎逻辑

## 后续修改建议

### 只想改数值
优先改 `heroes.js`。

这里主要放：
- 英雄名称
- 血量 / 攻击 / 射程 / 消耗
- 被动说明
- 技能说明

### 想改界面
优先改 `style.css`。

这里主要放：
- 颜色
- 字体
- 按钮大小
- 面板布局

### 想改战斗逻辑
改 `game.js`。

这里主要放：
- 行动点规则
- 移动 / 攻击 / 技能结算
- 状态效果
- 结算统计

## GitHub Pages 上传方式

1. 把这四个文件放到仓库根目录。
2. 仓库名保持公开（Public）。
3. 打开 `Settings -> Pages`。
4. 选择 `Branch: main`，`Folder: /root`。
5. 保存后等待网址生成。
